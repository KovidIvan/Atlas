# Атлас — ИИ-проводник для гостей Беларуси и Узбекистана

Модульная платформа адаптации иностранных студентов и гостей: персональный план по документам, проверенная карта города «Первые 48 часов», ИИ-ассистент **AIst / Лайлак**, разговорник, SOS-контакты и мини-кабинет международного отдела вуза.

Пилотный модуль разработан для направления **Беларусь ↔ Узбекистан** на базе **ВГУ им. П. М. Машерова (Витебск)**. Архитектура спроектирована так, чтобы любой университет Беларуси и любую страну-партнёра можно было подключить добавлением одного JSON-файла — без изменения программного кода.

---

## Что внутри

* **Личный план по документам (`rules.py`)** — детерминированный расчёт сроков регистрации и шагов адаптации **без участия языковых моделей** (0% галлюцинаций). Учитывает гражданство, страну визита, тип жилья (общежитие, отель, частное жильё), дату въезда и ключевые миграционные нюансы — например, невозможность бесплатной онлайн-регистрации на `e-pasluga.by` при въезде в Беларусь через территорию РФ.
* **Карта «Первые 48 часов» (`static/app.html`, Leaflet + OpenStreetMap)** — 21 проверенная точка в Витебске с точными координатами зданий (главный корпус ВГУ, общежития № 1–3, 5, 6, здравпункт, ОГиМ всех трёх районов и УГиМ, 3-я поликлиника, круглосуточная аптека № 127, Беларусбанк, МТС, A1, точки восточной кухни и гипермаркеты), фильтры по категориям, «Халяль» и «Доступная среда», построение маршрута в один клик.
* **ИИ-ассистент AIst / Лайлак (`ai.py`)** — работает по принципу **Strict RAG**: отвечает только по проверенным карточкам базы знаний, а ссылки на источники и даты проверки подставляет сам бэкенд по ID карточек. Если ответа в базе нет, ассистент не додумывает, а предлагает передать обращение специалисту международного отдела вуза.
* **Фото-переводчик вывесок и объявлений (`bot.py`)** — распознавание и перевод через Vision-модель прямо в Telegram. Изображение обрабатывается в оперативной памяти (`BytesIO`) и никогда не записывается на диск.
* **Мини-кабинет международного отдела вуза (`/admin`)** — просмотр подключённых модулей и их горячая перезагрузка, автоматический мониторинг изменений на сайтах НПА (`e-pasluga.by`, `mfa.gov.by`, `pravo.by`, `lex.uz`, `emehmon.uz`), ответы на обращения студентов (с доставкой прямо в Telegram) и обезличенная статистика частых тем.

## Конфиденциальность (Privacy-by-Design)

Безопасность данных заложена в архитектуру с учётом **Закона РБ № 99-З «О защите персональных данных»**, **Указа Президента РБ № 60** и **ст. 27-1 Закона РУз № ЗРУ-547**:

1. **Zero-PII база данных:** «Атлас» не запрашивает и не хранит ФИО, номера и сканы паспортов, телефоны, email и домашние адреса. В SQLite сохраняются только обезличенные параметры поездки.
2. **Локальный Privacy Firewall (`ai.scrub_pii`):** до отправки любого текста во внешний LLM API или в базу обращений регулярные фильтры автоматически скрывают случайно введённые номера паспортов, ПИНФЛ/личные номера, телефоны, банковские карты и email.
3. **Право на забвение:** обязательный экран согласия при `/start` в Telegram + мгновенное безвозвратное удаление всех записей пользователя командой `/delete_data` или кнопкой в интерфейсе.
4. **Суверенный режим ИИ:** клиент в `ai.py` совместим с OpenAI API, поэтому проект переключается с облачной модели на локальную (`Ollama` / `vLLM` на сервере вуза в РБ) изменением двух строк в `.env` — в этом режиме **0 байт данных покидает страну**.

## Архитектура проекта

Компактный асинхронный монолит на **Python 3.11+**: один процесс запускает FastAPI (API + Telegram Mini App + кабинет вуза), Telegram-бота (`aiogram 3`) и фоновый цикл проверок. Без тяжёлых сборок фронтенда, отдельных серверов БД и векторных хранилищ.

```text
Atlas/
├── main.py                # Единая точка входа: FastAPI + aiogram + фоновые задачи
├── config.py              # Загрузка .env и определение суверенного режима ИИ
├── db.py                  # Async SQLite (Zero-PII профили, чек-лист, тикеты, НПА, статистика)
├── loader.py              # Автозагрузка и Pydantic-валидация сменных модулей из data/
├── rules.py               # Детерминированный движок расчёта сроков и чек-листа
├── ai.py                  # Privacy Firewall + Strict RAG + Vision-перевод в RAM
├── monitor.py             # Фоновый мониторинг изменений НПА + напоминания о дедлайнах
├── bot.py                 # Telegram-бот (aiogram 3): согласие 99-З, чат, фото, SOS, тикеты
├── web.py                 # FastAPI: JSON API + раздача Mini App и кабинета вуза
├── requirements.txt       # Минимальный набор зависимостей (7 пакетов)
├── .env.example           # Шаблон переменных окружения
├── static/
│   ├── app.html           # Telegram Mini App (План, Карта, Ассистент, Справка / SOS)
│   └── admin.html         # Мини-кабинет международного отдела вуза
└── data/                  # Сменные модули данных (масштабирование без правки кода)
    ├── countries/
    │   ├── by.json        # Модуль «Беларусь»: правила, НПА, ЕПЭУ, культура, фразы, SOS
    │   └── uz.json        # Модуль «Узбекистан»: правила, emehmon.uz, культура, фразы, SOS
    └── universities/
        └── vsu_vitebsk.json  # Модуль «ВГУ им. П. М. Машерова»: контакты, шаги, 21 точка карты
```

## Быстрый старт

### Windows (PowerShell)

```powershell
git clone https://github.com/KovidIvan/Atlas.git
cd Atlas
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python main.py
```

### Linux / macOS

```bash
git clone https://github.com/KovidIvan/Atlas.git
cd Atlas
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python main.py
```

### Что доступно сразу после запуска

Проект **работает из коробки даже без `BOT_TOKEN` и `LLM_API_KEY`** (включается автономный режим по проверенной базе знаний):

* **Приложение гостя (Mini App в браузере):** `http://127.0.0.1:8000/app`
* **Кабинет международного отдела вуза:** `http://127.0.0.1:8000/admin` *(токен по умолчанию: `atlas-vsu-2026`)*
* **Документация OpenAPI (Swagger):** `http://127.0.0.1:8000/docs`

## Настройка `.env`

| Переменная | Назначение | Значение по умолчанию |
| :--- | :--- | :--- |
| `BOT_TOKEN` | Токен Telegram-бота от `@BotFather` (если пустой — работает только Web/Mini App) | *(пусто)* |
| `APP_BASE_URL` | Публичный `https://` URL для кнопки Telegram Mini App (например, через `cloudflared` / VPS) | `http://127.0.0.1:8000` |
| `HOST` / `PORT` | Адрес и порт веб-сервера FastAPI | `127.0.0.1` / `8000` |
| `ADMIN_TOKEN` | Токен доступа к кабинету вуза (`/admin` и `/api/admin/*`) | `atlas-vsu-2026` |
| `LLM_BASE_URL` | URL OpenAI-совместимого API (OpenAI, OpenRouter, Gemini, DeepSeek или локальная Ollama) | `https://api.openai.com/v1` |
| `LLM_API_KEY` | API-ключ LLM (если пустой — ответы берутся напрямую из проверенной базы карточек) | *(пусто)* |
| `LLM_MODEL` | Модель для Strict RAG | `gpt-4o-mini` |
| `LLM_VISION_MODEL` | Модель для перевода фото вывесок в Telegram | `gpt-4o-mini` |
| `NLA_CHECK_INTERVAL_MIN` | Интервал проверки сайтов НПА (в минутах) | `360` |
| `REMINDER_CHECK_INTERVAL_MIN` | Интервал проверки приближающихся дедлайнов (в минутах) | `60` |

Пример переключения на **локальную суверенную модель (Ollama)** без отправки данных за пределы сервера:

```env
LLM_BASE_URL=http://127.0.0.1:11434/v1
LLM_API_KEY=ollama
LLM_MODEL=qwen2.5:7b
LLM_VISION_MODEL=qwen2.5vl:7b
```

## Масштабирование: как подключить новый вуз или страну

Платформа использует двухслойную модульность (`loader.py`):

1. **Подключить новый университет Беларуси** (например, БГУ, БНТУ, ВГМУ):
   * Скопируйте `data/universities/vsu_vitebsk.json` в `data/universities/<vuz_id>.json`.
   * Заполните контакты международного отдела, локальные шаги заселения/медосмотра и точки карты.
   * Нажмите **«Перезагрузить модули из data/»** в `/admin` — новый вуз сразу появится в списке приложения.
2. **Подключить новую страну** (например, Китай, Туркменистан, Индия):
   * Создайте файл `data/countries/<iso_code>.json` по структуре `by.json` / `uz.json` (правила регистрации, ссылки на НПА, карточки, разговорник, SOS).
   * Перезагрузите модули в `/admin`.

## Основные API-эндпоинты

* `GET /api/modules` — список загруженных модулей стран и вузов, статус защиты данных.
* `POST /api/plan` — расчёт и сохранение персонального плана по документам.
* `POST /api/plan/toggle` — отметка выполнения шага в чек-листе.
* `GET /api/map` — точки карты вуза/города с фильтрами `category`, `halal`, `accessible`.
* `POST /api/ask` — вопрос к AIst / Лайлак (с Privacy Firewall и возвратом проверенных источников).
* `GET /api/phrasebook`, `GET /api/sos` — разговорник и экстренные контакты.
* `POST /api/tickets` — создание обезличенного обращения в международный отдел вуза.
* `DELETE /api/user/{tg_id}` — полное удаление данных пользователя (Закон РБ № 99-З).
* `GET /api/admin/overview`, `POST /api/admin/reload`, `POST /api/admin/check-nla`, `POST /api/admin/tickets/{id}/reply` — API кабинета вуза (требует заголовок `X-Admin-Token`).
