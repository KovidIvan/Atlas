# «Атлас» — ИИ-проводник для гостей Беларуси и Узбекистана

Компактная модульная Python-платформа адаптации иностранных студентов и гостей (пилот — коридор **Беларусь ↔ Узбекистан** на базе **ВГУ им. П. М. Машерова**, с масштабированием на все университеты Беларуси).

## Архитектура (9 Python-файлов)

- `main.py` — единая точка входа (FastAPI + Telegram-бот + фоновые проверки).
- `config.py` — настройки окружения (`.env`), переключение `Облачный LLM ↔ Локальный суверенный ИИ`.
- `loader.py` — загрузчик и Pydantic-валидатор сменных модулей из `data/`.
- `rules.py` — **детерминированный расчёт сроков регистрации и чек-листа** (0% галлюцинаций ИИ, учёт въезда в РБ через РФ vs напрямую).
- `ai.py` — ассистент **AIst / Лайлак**: локальный **Privacy Firewall** (обезличивание ПД до отправки в ИИ), **Strict RAG** с подстановкой ссылок бэкендом и фото-переводчик в RAM.
- `db.py` — `SQLite` в режиме **Zero-PII** (без хранения ФИО, паспортов и телефонов) + удаление всех данных в 1 клик (`/delete_data`).
- `monitor.py` — фоновый мониторинг изменений НПА (`e-pasluga.by`, `mfa.gov.by`, `pravo.by`, `lex.uz`, `emehmon.uz`) и напоминания о сроках.
- `bot.py` — Telegram-бот (`aiogram 3`) с экраном информированного согласия (Закон РБ № 99-З).
- `web.py` — FastAPI API + раздача Mini App (`static/app.html`) и мини-кабинета вуза (`static/admin.html`).

## Быстрый старт (Windows / Linux)

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python main.py
```

После запуска сразу доступны (даже без `BOT_TOKEN` и `LLM_API_KEY`):
- **Telegram Mini App (режим браузера):** http://127.0.0.1:8000/app
- **Мини-кабинет международного отдела вуза:** http://127.0.0.1:8000/admin (токен по умолчанию: `atlas-vsu-2026`)

## Как добавить новый вуз Беларуси или новую страну (без правки кода)

1. Создайте JSON-файл по шаблону в `data/universities/<vuz>.json` или `data/countries/<code>.json`.
2. Нажмите **«Перезагрузить модули из data/»** в кабинете `/admin` (или перезапустите сервер).

## Конфиденциальность и суверенный режим

- **Zero-PII:** сервис не собирает ФИО, паспорта и номера телефонов.
- **Privacy Firewall:** `ai.scrub_pii()` скрывает случайные паспорта, телефоны, карты и email до обращения к ИИ; фото вывесок обрабатываются только в RAM.
- **Суверенный режим (0 байт за пределы РБ):** укажите в `.env` адрес локальной модели Ollama/vLLM на сервере вуза (`LLM_BASE_URL=http://127.0.0.1:11434/v1`).
